# Подарочные сертификаты LEOLSBEER

Страница, на которой продавец выписывает подарочный сертификат: выбирает формат, вписывает сумму и имя, скачивает готовый PNG. Номер подставляется сам, каждый сертификат попадает в журнал, на кассе его можно найти по номеру и отметить «погашен».

## Что в репозитории

| Файл | Зачем |
|---|---|
| `index.html` | Генератор. Работает на GitHub Pages |
| `config.js` | Адрес API журнала |
| `bg-h.png`, `bg-v.png` | Фоны: обычный и с пожеланием |
| `server/api.php` | API журнала для вашего PHP-хостинга |
| `server/schema.sql` | Таблица журнала + уже выданные №1429 и №1430 |
| `server/config.sample.php` | Образец настроек API |

## Как запустить

**1. Журнал на хостинге**

1. Создайте базу MySQL и выполните `server/schema.sql` (phpMyAdmin → Импорт).
2. Залейте `api.php` в папку на сайте, например `leolsbeer.ru/certs/`.
3. Рядом создайте `config.php` по образцу `config.sample.php`: доступ к базе, пароль для продавцов и адрес страницы на Pages.

Пароль передаётся параметром в адресе, а не заголовком Authorization: Reg.ru его срезает.

**2. Страница на GitHub Pages**

1. В `config.js` впишите адрес API: `window.CERT_API = "https://leolsbeer.ru/certs/api.php";`
2. Settings → Pages → Deploy from a branch → `main` / root.

Без адреса API генератор тоже работает: сертификаты скачиваются, номер ведётся в браузере, но журнала и погашения нет.

## Поменять фон или адреса магазинов

- Фоны: экспортируйте из Figma без текста в тех же размерах (820×312 и 586×842) и замените `bg-h.png` / `bg-v.png`.
- Адреса и строка «Даёт право…»: константы `ADDR_H`, `ADDR_V`, `RIGHT_H`, `RIGHT_V` в начале скрипта в `index.html`.
- Первый номер, если журнал пуст: `START_NUM`.
